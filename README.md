Module 6 – Strings, Classes, and File I/O (module6.cpp)

This program demonstrates how to use:

Strings

Classes

File Input/Output

The program includes an Item class with the attributes:

string name

int quantity

The class has two methods:

saveToFile() → saves the item data into a file named items.txt

loadFromFile() → reads the file and prints the content

This module teaches how to write to a file using ofstream and how to read from a file using ifstream.

Module 11 – Constructors and Destructors (module11.cpp)

This program shows how constructors and destructors work in C++.

The Product class has:

Private attributes: id, name, and price

A constructor to initialize these values

A destructor that prints a message when the object is destroyed

A printDetails() method to display product information

This module teaches object lifecycle and how constructors and destructors behave during program execution.
