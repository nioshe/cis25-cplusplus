# Week 8 – Bank Account Simulation

This program simulates a simple bank account using C++. It performs a deposit, several purchases, displays the final balance, and saves all transactions to a text file.

## What the Program Does
- Adds an initial deposit  
- Processes three purchases  
- Updates and displays the current balance  
- Saves each transaction to `transactions.txt`  

## How to Run the Program

### Using Visual Studio
1. Open a C++ Console Application  
2. Add `week8.cpp` to the project  
3. Run using Ctrl + F5

### Using g++
g++ week8.cpp -o week8
./week8

## Example Transaction Log
The file `transactions.txt` generated by the program will look like this:

Deposit: $100.00
Purchase - Coffee: $4.50
Purchase - Book: $25.00
Purchase - Lunch: $12.75
